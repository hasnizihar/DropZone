# DROPZONE

## Master Development Prompt: Universal Desktop Downloader

You are a Senior Software Architect, Full-Stack Engineer, Desktop Application Developer, Python Engineer, UI/UX Designer, and QA Engineer.

Your task is to design, architect, implement, test, and deliver a professional universal desktop downloading application named **DROPZONE**.

Do not create a simple downloader wrapper or a static UI prototype. Build a modular, extensible, reliable desktop application with real downloading capabilities.

Work independently, inspect the environment, make reasonable technical decisions, and implement the project incrementally.

---

# 1. PRODUCT VISION

**Product:** DROPZONE\
**Product type:** Universal Desktop Download Manager\
**Initial platform:** Windows 10/11\
**Future platforms:** macOS and Linux\
**Architecture:** Local-first desktop application\
**Primary language:** TypeScript\
**Backend language:** Python

### Main objective

Create one desktop application capable of downloading supported content from a wide range of online sources.

Supported content categories:

1. Videos
2. Audio
3. Images and image galleries
4. Documents
5. General files
6. Playlists and collections
7. Batch downloads

The application should automatically recognize supported URLs, identify the appropriate downloading engine, analyze available formats, and let users manage downloads through a unified interface.

Do not claim universal compatibility. Build an extensible architecture that can support new sources through provider adapters.

```
interface DownloadProvider {

  canHandle(url: string): Promise<boolean>;
```

# 10. COMMUNICATION PROTOCOL

Electron Main Process and Python worker must communicate using structured JSON Lines.

Example worker messages:

```
{
  "type": "job_progress",
  "jobId": "uuid",
  "progress": 42.5,
  "downloadedBytes": 12500000,
  "totalBytes": 30000000
}
```

```
{
  "type": "job_completed",
  "jobId": "uuid",
  "outputPath": "C:/Downloads/video.mp4"
}
```

```
{
  "type": "job_failed",
  "jobId": "uuid",
  "error": {
    "code": "SOURCE_UNAVAILABLE",
    "message": "The source is unavailable."
  }
}
```

Requirements:

- Version the protocol.
- Validate every message.
- Use stdout only for protocol messages.
- Send diagnostic logs to stderr.
- Support cancellation messages.
- Handle unexpected worker termination.
- Reconnect or restart workers safely.
- Never trust worker output without validation.
