# DROPZONE Roadmap

## Version 1.0.0 (MVP)

- [x] Project Foundation & Workspace Setup (Milestone 1)
- [x] Modern Dark UI Shell with Acid Lime Accent (Milestone 1)
- [x] Typed Secure IPC Bridge (Milestone 1)
- [x] Python Worker & JSON Lines Heartbeat Protocol (Milestone 2)
- [x] yt-dlp Video & Audio Extraction & URL Analyzer (Milestone 3)
- [x] Download Queue State Machine & Scheduler (Milestone 4)
- [x] Direct HTTP/HTTPS Chunked Downloader with Resume (Milestone 5)
- [x] Image & Gallery Extraction (Milestone 5)
- [x] Batch & Playlist Processing (Milestone 6)
- [x] FFmpeg Stream Merging & Audio Conversion (Milestone 7)
- [x] Settings Persistence & History Management (Milestone 8)
- [x] QA & Fault-Tolerance Hardening (Milestone 9)
- [x] Windows NSIS Installer & Portable Executable (Milestone 10)

## Future Considerations (Post-1.0)

- Cross-platform distribution for macOS (Universal DMG) and Linux (AppImage / Flatpak).
- Browser extension for one-click download redirection into DROPZONE.
- Bandwidth scheduling (night-time download windows).
- Torrent / P2P provider adapter.
